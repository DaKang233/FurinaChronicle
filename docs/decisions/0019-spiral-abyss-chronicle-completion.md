# ADR 0019：深境螺旋 Chronicle 完成证据

状态：Accepted

确认日期：2026-10-19

## 背景

ADR 0017 保存了深境螺旋不可变观察，但没有定义 Chronicle 的“完成一期”节点。存在记录、`Completeness.Complete` 或满星都不能单独等同于通关。

## 选项

1. 只要接口返回一期记录就视为完成。
2. 达到固定总星数才视为完成。
3. 使用版本化模式规则定义目标末关，以明确的目标 Chamber 结果作为正面完成证据；完整观察缺少目标时可以判断未完成，部分观察缺少目标时保持未知。

## 决定

采用选项 3。

- 首版规则 ID 为 `genshin-spiral-abyss-completion-v1`，目标为第 12 层第 3 间；规则 ID、目标层和间属于 Chronicle 规则版本，不写回挑战事实或 Portable。
- 规范化 `SpiralAbyssChamberResult` 表示该间已经形成结果，因此目标 12-3 存在就是正面完成证据；星数可以为 0～3，完成与满星分开。
- 观察范围完整且没有目标 12-3 时为 `NotCompleted`；范围为 Partial／Unknown 且没有目标时为 `Unknown`。
- 同账号、同模式、同期次的 Main 完成候选最多一个，身份由账号副本、模式、期次和完成规则版本构成。
- 从全期有效观察中选择最早可证明完成的证据，不使用最高星、最晚导入或当前最佳证据代替。迟到的更早证据更新同一候选，不生成第二个节点。
- 目标 Chamber 有可靠 `CompletedAt` 时使用该时间；只有 Unknown 时间时 `Occurred` 为空，依次用观察／抓取时间排序并明确显示依据。周期结束时间不得冒充完成时间。
- 后续成绩提升、A→B→A 和重复观察仍可进入 Challenge Profile，但不增加主时间线完成节点。
- 首版生产 Contributor 仅支持深境螺旋；幻想真境剧诗与幽境危战只允许合成测试验证退化，不因本 ADR 宣称产品化。

## 原因

目标末关是“完成”而非“满星”的直接证据，并允许 Partial 观察携带正面事实；同时避免把缺失、期末或抓取时间解释为完成。

## 后果

- 挑战采集适配器必须只把已经形成结果的 Chamber 映射为 `SpiralAbyssChamberResult`。
- 若未来螺旋结构改变，新增规则版本和适用范围，不静默改写 v1 历史解释。
- 完成节点是 Derived Chronicle 候选，不是新的挑战规范化事实。

## 测试要求

- 覆盖 Completed／NotCompleted／Unknown、首见已完成、完成后提星、迟到更早证据和删除证据后重算。
- 目标 Chamber 无可靠时间时不伪造 Occurred；有可靠时间时保留原偏移和精度。
- 同一期主时间线最多一个完成节点，Challenge Profile 保留有效观察历史。

## 确认

维护者于 2026-10-19 要求按 Phase 8B.6 规划实施，接受本 ADR 所列推荐首版语义。
