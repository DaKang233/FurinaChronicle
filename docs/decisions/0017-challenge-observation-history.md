# ADR 0017：挑战观察身份、回返与乱序历史

状态：Proposed

日期：2026-10-18

## 背景

挑战状态会在同一期内多次变化，也可能由文件乱序导入。只按全历史内容哈希去重会吞掉 A→B→A 的真实回返；只按最新抓取时间覆盖又会丢失完整证据或让迟到记录倒退当前视图。

## 建议决定

- 首批生产支持仅深境螺旋；模式代码和官方期次 ID 构成账号副本内自然范围，周期不充当身份。
- 每份不可变观察使用稳定 `ObservationId`。同一来源观察 ID 或 Portable 引用重试且内容相同为 NoOp；同 ID 不同内容为 Conflict。
- 在线连续采集没有稳定来源 ID 时，仅与同一期按可信观察顺序相邻的规范内容比较。相邻内容相同为再次核验，不新增业务观察；A→B→A 且具有严格递增可信观察时间或来源序列时保留第二个 A。
- 历史文件按稳定观察引用和可信观察时间插入。迟到观察可以补充历史，但不能仅因导入较晚成为当前最佳证据。
- 同一可信观察时刻内容矛盾时保留结构化 Conflict，不按导入顺序覆盖；缺少足够身份和顺序证据时返回 Ambiguous，不制造顺序。
- Complete、Partial、Unknown 必须连同模式、期次、楼层／间和字段覆盖范围解释。Partial 不覆盖 Complete；非包含关系 Partial 不合成为 Complete。
- Portable 首版携带全部不可变挑战观察历史和来源端 provenance；不携带本机 Undo、容量配置或 Tombstone。

## 后果

- 当前最佳证据视图与观察历史分离，并使用确定性的证据选择规则。
- 完成节点和各模式完成条件留给对应领域规则／8B.6；8B.5 不以“存在记录”或“满星”推断完成。
- 剧诗和未知完成时间 fixture 只验证模型边界，不表示模式已产品化。

## 确认前限制

本 ADR 未经维护者确认时不得标记 Accepted，不得创建依赖上述判重和 Portable 语义的生产 Schema。
