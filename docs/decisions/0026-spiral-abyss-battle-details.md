# ADR 0026：挑战详情兼容

状态：内部实施记录；格式未公开发布

深渊观察在每间下保存官方明确提供的上／下半阵容、敌人和秒级精度的发生时间。整体完成仍要求上下半均有有效且顺序正确的时间。缺少证据时保留未知，不以采集时间代替。新增信息是该次观察的内容，沿用 ADR 0017 的历史判重和 ADR 0019 的 12-3 完成语义。

本轮还保存官方明确返回的战斗／胜利次数、最深进度、总星数以及出战、击破、最强一击、承伤、元素战技和元素爆发排行。缺失统计为空，不由本地楼层推断；排行顺序保留，值使用非负 64 位整数。该统计属于观察内容，变化遵循已有相邻判重规则。

SQLite Schema 保持 12。旧观察载荷没有半场详情时继续读取并保留为缺失，无数据迁移。内部挑战 Portable 只有在含半场详情或官方统计时写入 2.0；既有 1.0 和 1.1 仍可直接读取。旧读取器接受未知次版本并忽略新增字段，主版本变化确保它会在导入前拒绝。完整 Archive 维持容器版本，有半场详情或官方统计时使用 1.1 挑战子数据集并标记为必需，使旧客户端在写入前明确拒绝。没有这些详情时继续使用 1.0 子数据集。详情字段、示例和验证规则见 [挑战历史规范](../specifications/CHALLENGE_HISTORY_V1.md)。


## 剧诗详情的内部扩展（2026-11-19）

本轮内部扩展承载剧诗官方总览／战斗统计、实际候补角色、出战角色的自有／试用／助演标识，以及塔罗幕标记与序号。沿用不可变观察和既有时间语义，不新建获取事件或完成规则。缺失标识为空，不默认推断自有；未知来源代码受控拒绝，不把助演角色计入玩家仓库。值为字符串的统计在采集边界规范化；官方明确返回的空字符串按参考契约表示零，缺字段仍为空。统计隐藏标记原样保存，展示遵守该标记。

初始／特邀角色和准入元素来自对应期次的版本化元数据，只作独立的期次说明，不写成玩家所有权或 OfficialApi 观察事实。旧观察不回填。

这些新增字段使用尚未公开的分类挑战 2.1 和 Archive 必需挑战子数据集 1.2；仅有深渊详情时继续使用 2.0／1.1，无详情时继续旧版本。2.0 分类读取器拒绝 2.1；只支持 Archive 子数据集 1.1 的旧读取器拒绝必需的 1.2。当前读取器也拒绝 2.0／1.1 冒称包含这些字段，防止降级包静默丢失。SQLite 仍为 Schema 12，新增私有可选字段为空时不写出，保留旧载荷的判重。公开发布前仍须新字段跨端验收。

## 幽境危战详情的内部扩展（2026-11-19）

沿用现有单人 Stages，不重写旧的关卡标识。多人使用同次观察的独立 multiplayer_stages，单人／多人不互相合并或推断。stygian_statistics 保存两类官方 has_data、最佳难度／总秒数和增辉角色；单关保留怪物 ID、描述／标签、最佳角色指标，阵容保留明确命座。没有数据的分支不据默认零值生成成绩；没有字段保持未知。最佳角色指标 1 为最强一击、2 为总伤害，其他非负代码保留并明确标为未知指标，不冒称 DPS。增辉名单不构成玩家持有角色或仓库变化。

官方秒数始终为成绩，单人和多人发生时间均未知；不以赛季起止、抓取时间或成绩推导时间戳。仍以 Partial 观察保存，统计改变形成新观察，抓取时间单独改变仍 NoOp。Schema 12 和不可逆删除／Undo／时间线完成规则不变。

新内容使用内部分类挑战 2.2／Archive 必需挑战子数据集 1.3；只有较旧详情时维持原先最低版本。新 Reader 拒绝将新增内容伪装成旧版本；旧 Reader 在写入前拒绝新版本。单人和多人都属于一个不可变观察和同一次原子提交，不能分开提交。公开发布仍需跨端文件验收。

## 剧诗卡牌与祝福结构化补齐（2026-11-19）

仍属当前未公开格式的内部实施，不改变 ADR 0017 的观察／判重或完成时间。TheaterRoundDetails 增加可选 buff_details 和 buff_summary：列表顺序及同名不同条目原样保留；每条含来源类别（choice_card／buff／splendour）、来源明确给出的非负 ID（可空）、名称、描述、公共图标、等级、强化标记和效果列表。没有来源 ID 的辉彩祝福不生成 ID；这些是观察内容，不建立按显示名称判定的全局身份。不推断等级、强化状态或发生时间。原 Buffs 兼容文本继续保留，旧观察不回填。

缺少结构化内容时可选属性完全不写入，确保旧内容序列化／判重稳定。真实内容变化沿用观察追加规则。便携 Wire 必须显式映射，私有 SQLite 仍 Schema 12。带结构化卡牌／祝福或结构化总览时使用分类挑战 2.3、Archive 必需挑战子数据集 1.4；没有新增内容时仍选择原最低版本。Reader 拒绝冒称更低版本的内容，旧 Reader 在写入前拒绝 2.3／1.4，不静默降级。UI 复用受信任公共图片缓存，资源失败继续显示来源文字；不把图片 URL 写入遥测。

公开发布前继续要求新字段跨端验收。本段不宣布格式已发布或取代其他 Accepted 决策。
