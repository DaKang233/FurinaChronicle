# ADR 0031：AI 提示词、用户称呼与本地只读工具

状态：Accepted（维护者 2026-11-22 要求全局提示词/称呼/工具设置，并明确选择“仅查询本地档案数据，只读；提供开关和每轮次数上限”）。扩展 ADR 0027/0028/0030 对工具的一概禁止；其他隐私及事实边界不变。

- 设备配置写入内部 Envelope v3，保留 v2 读取和旧密钥绑定。全局配置保存用户称呼、自定义系统提示词、工具开关和每轮调用上限。称呼仅用于本地消息标记与人类可读报告，不作为身份或发送给模型。系统提示词进入每次发送审查，不携带密钥，附加游戏范围的去标识化规则继续作用于它。
- 自定义提示词控制助手风格和分析要求；应用固定的数据来源、去 UID、只读范围及工具限制不被替换。提示词本身不获得文件、网络或写入权限。
- 工具默认关闭；每个用户消息的实际调用总数可设 0～500（默认 10，0 等于不调用），并受总生成时限 5 分钟约束。最后一次调用后只能请求最终回答，不能再执行新调用。关闭或当前无可用资料时不向服务声明工具。
- 首版仅提供当前会话已附加范围内的证据筛选、指定证据及本地来源可用性核验、确定性抽卡统计。查询读取已有会话白名单快照，不自动刷新游戏、跨账号/档案扩大范围或加载未审查的原始响应。读取证据时可以通过既有 Repository 核验来源是否还在本地；未知或已删除不能冒充实时事实。
- 工具不接受 UID、账号 GUID、SQL、文件路径或 URL。参数固定、结果有界，未知工具或参数拒绝。提供给模型的结果只有既有白名单 DTO 和来源可用性说明；本地身份及凭据不进入工具结果。
- 发送确认页明确列出本轮工具、范围、调用上限及结果发给当前服务的行为；该次授权覆盖同一用户轮的受限只读调用。整档案 UID 授权继续逐轮要求，单账号不发送 UID。
- 本地仅保存每轮工具名称、数量和安全摘要；中间参数、响应 ID、原始工具结果不单独持久化或日志记录。已有会话快照/回答仍受关联会话的永久删除保护。多轮续聊不依赖远程会话。
- 三种原生协议实现相应 function/tool_use 往返。旧 Ollama 配置保留原文本/图片路径，首版不为其增加工具。不开启服务端搜索、命令、文件访问、联网、任意函数或领域写入工具。

协议内必要的思考签名/加密片段仅在同一个用户轮内存中续接给原服务，不作为回答显示，不保存到会话、报告或日志，也不跨用户轮回放。Responses 请求工具时显式请求 reasoning.encrypted_content，仍保持 store=false。
