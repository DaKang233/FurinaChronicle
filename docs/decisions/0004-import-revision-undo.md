# ADR 0004：分类导入、修订和有限撤销

状态：Accepted

导入按数据类别选择 `AddOnly` 或 `Upsert`，未来可以增加逐条 `Manual`。覆盖形成 Revision。数据修改按 ChangeSet 记录，撤销按档案计数，默认 3 次，可设置为 0 关闭，或设置为 1～1000；不提供无限撤销。

附件和大型 Raw Snapshot 可以作为撤销材料保留。空间不足且需要提前清理旧历史时，必须提示用户并在用户确认后才继续新操作。

操作历史、来源修订和同步 Journal 必须分离；普通导入不因源缺少记录而删除目标记录；撤销以新的反向 ChangeSet 实现，不重写历史。
