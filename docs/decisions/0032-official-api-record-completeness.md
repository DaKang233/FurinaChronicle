# ADR 0032：官方 API 成功记录的完整度与全字段解析

状态：Accepted（维护者 2026-11-23 明确规定：从官方 API 采集且成功的所有记录一律视为完整，并要求 Response 能够解析其中全部字段）。

## 决定

1. 所有领域从官方 API 成功采集的记录统一声明 `DataCompleteness.Complete`。不再只适用于挑战。Complete 的依据是“该次官方返回记录已完整解析并按所属领域可靠承载”，不能只有来源标签、HTTP 200、retcode=0 或反序列化未抛异常。
2. Response／DTO 必须能解析所接入响应的全部字段，包括每层对象、数组、可选字段和分支；建立字段清单，逐项标注来源路径、类型、缺失／null 语义、映射去向与校验。不能只读取 UI 用到的字段，或以默认忽略未知 JSON 属性作为全字段覆盖的证据。
3. 传输完成、官方业务状态成功、完整响应解析和必要校验、事实安全承载均通过，才是本规定中的“采集成功”。无法解析、截断、业务错误、风控失败、必要字段非法或新增字段尚未支持时，不得将部分结果以完整成功提交。应报告受控的解析／兼容问题；涉及同一原子采集批次时遵守既有全部校验后提交规则。没有数据与采集失败分开，不补造事实。
4. 新增未知字段必须被检测。仅通过 JsonExtensionData／JsonElement 捕获原文不代表已理解和承载；全字段清单及对应测试明确后才能认定覆盖。允许在适配器中解析错误码、分页和其他控制字段并用于校验，而不把控制字段变成领域事实。不能把所有响应机械塞进领域公共基类。
5. 已解析的游戏事实不能因当前 UI 不显示而静默丢失。属于事实的字段明确映射至领域及其持久化；受支持的 Portable／Archive 往返按既有保真规则实施，新增承载需要时先演进对应契约和版本。缓存资源仍按缓存策略处理。凭据与安全会话字段可在受控适配器中使用，继续禁止进入普通事实导出、日志、遥测、报告和公开备份。
6. 范围仍按领域／数据类型声明。单条记录、单页结果或单次状态响应的 Complete，不表示已枚举账号历年记录、所有接口、所有分页或完整仓库，也不代表通关、满星、事实绝对正确。分页采集仍要遵守实际分页终止和增量／全量语义，不能从已读取页面完整推导尚未读取页面完整。
7. 官方只返回已装备武器时，完整的是该次返回的装备结果；不得把该响应变成“玩家全部武器仓库完整”的声明。领域应分别表达单次来源记录与更大集合的覆盖范围；不能为满足枚举值而抹掉未装备武器不可见的事实。
8. 规则用于新的官方采集。旧不可变观察、既有事实 Revision、来源文件及 Portable／Archive 中的完整度和内容指纹不批量重标。导入记录即使 provenance 为 OfficialApi，也不能仅凭该值改成 Complete。其他来源继续使用领域声明的 Complete／Partial／Unknown。

## 示例

- 官方返回某角色的一条完整记录：Response 解析并承载其中所有字段，成功后该记录为 Complete；不能仅因已保存等级、命座就忽略同一条记录中返回的其他属性。
- 官方返回一期挑战的概要，细节分支明确为空：解析并保存实际返回的全部内容后可为 Complete；缺失内容仍为空，不据此生成完成时间或通关节点。
- 只查询抽卡第一页：本页每条成功记录为 Complete；不声称账号全部抽卡历史已取得。新出现一个未识别的嵌套字段时，兼容校验不能继续宣称全字段成功。
- 登录响应中的安全凭据：由安全适配器解析及保管，不因“全部字段”要求进入游戏事实、可移植包或日志。

## 与既有决定的关系

扩展 ADR 0011 的共享完整度约束及 ADR 0017 的官方挑战特例，将成功官方记录为 Complete 提升为全局规则；保留它们对声明范围、不可变观察、相邻判重、冲突及低层完整度不能提升高层的决定。覆盖旧文档中将这项要求限制为挑战的表述。

本 ADR 不强制每种既有记录立即增加同名数据库字段，也不以未迁移的旧 Row 缺字段为由伪造 Complete。承载字段、版本及迁移仍按领域落地；未完成的适配列为 implementation gap，不能把规范 Accepted 当作代码已经实现。

## 当前实施状态

本轮固化全局契约，并完成静态覆盖核查；尚未完成全部官方 Response 的逐字段适配和成功门禁。前一轮挑战采集已设置 Complete，但其有限 DTO 映射不等于本 ADR 的全部字段验收已通过。真实响应对照、受控 fixture、持久化与可移植往返仍需逐入口补齐，见 [实施差距](../development/OFFICIAL_API_FIELD_COVERAGE.md)。不修改生产数据，不把既有测试通过记为全字段支持证据。
