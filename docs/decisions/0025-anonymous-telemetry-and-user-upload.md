# ADR 0025：匿名化遥测与用户主动上传

状态：Accepted

## 背景

维护者允许默认收集真正匿名化的应用遥测。个人档案与可关联到用户的数据仍由用户决定每次是否上传。

## 决策

- 提供遥测功能的版本可默认开启匿名化遥测，仅用于开发、错误诊断、性能和使用体验改进。应用说明所发送的类别和用途，并提供设置开关。关闭后停止后续发送。
- 默认发送的载荷在离开设备前完成匿名化。可持续区分用户、账号、设备或安装实例的标识，包括稳定的随机或哈希标识，均不属于默认匿名化遥测。只去除姓名或 UID、只脱敏原始日志、由服务端收到后再匿名化，都不足以进入默认通道。只能发送足以达到匿名化要求的计数、汇总或错误类别。
- 游戏档案、账号记录、可关联的诊断报告和其他涉及用户本身的数据，由用户主动发起上传。发起前展示接收方、用途和本次范围。游戏通行证凭据、验证码、授权链接等秘密不进入遥测、诊断报告、云备份或统计投稿。
- 全服统计采用单次投稿。对应页面说明范围和用途，点击明确标注的上传按钮即授权本次提交。查看统计结果、创建账号或使用云备份均不触发投稿。云备份数据不自动纳入统计。

## 实施与验证

本 ADR 确认默认行为和数据边界。端点、事件字段、保留期限及匿名化验证随实际实现确定。上线前验证发出的载荷符合边界、关闭遥测可停止发送，以及本地档案在离线状态下仍可使用。个人数据上传继续沿用独立授权和各功能的操作确认。
