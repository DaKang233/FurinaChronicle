# ADR 0027：只读 AI 分析与去标识化发送

状态：Accepted（维护者于 2026-11-21 授权实施既有 AI 路线图；UID 规则按本轮补充确认）

实施状态：首版工程与 Windows 合成数据交互已验证；Android 真机待验收，详见 [AI 验收记录](../development/AI_ANALYSIS_ACCEPTANCE.md)。

> 会话仅在内存、离页清空的首版限制已由 [ADR 0028](0028-local-ai-chat-and-attachments.md) 替代。当前支持本地聊天与附件，其他授权和只读规则继续有效。

## 决定

- AI 是独立、可选的导航页，不成为领域功能或云服务的前置条件。首版读取当前已实现的抽卡、角色／武器观察、手工获取和三类挑战历史，复用确定性统计，支持账号／档案与日期范围、追问及单独的 Markdown 报告导出。
- 模型服务由用户配置并承担费用，首版支持 OpenAI 兼容 Chat Completions 和 Ollama。API 密钥仅进本机平台安全存储，不进普通设置、日志、Portable、Archive 或请求预览。此阶段不自动保存会话或改写领域事实／修订（时间线查询可更新其可重建缓存）；结果只在独立会话中保留，用户可主动导出报告。
- 构建模型资料必须使用专用白名单 DTO，不序列化账号、观察对象、SQLite 行或完整备份。单账号 UID、通行证身份、昵称、档案名、备注、装备实例 ID、外部记录 ID、本地 GUID、来源引用、图片 URL 和凭据均不进入资料。公开物品名称从可信元数据解析；未知或不可信名称降级为类别，不能直接使用导入的自由文本。
- 单账号始终以代称区分且不发送 UID。整个档案默认使用 UID，但必须在本次发送弹窗明确获得同意；不接受时改为编号。编号按 UID 数值升序分配“账号 01、账号 02……”，同 UID 使用本地稳定次序区分副本，不合并事实。无有效数字 UID 的账号排在有效 UID 后，且不发送占位身份。以 E001 等会话内证据编号引用本地事实。真实引用映射只在本机持有，支持查看所据记录。日期只发送分析所需的日期粒度，未知发生时间不得用采集时间替代。
- 对用户问题和即将重发的对话进行标识清理；疑似凭据拒绝发送。此措施是去除直接标识，不承诺让游戏事实组合完全不可再识别。自由文本不能保证覆盖所有个人信息，发送前必须可审查完整正文。
- 默认不发送任何档案资料。每次发送（包括追问）都先展示接收服务、模型、类别、范围和实际消息正文，并取得本次操作确认。连接测试只发送固定诊断文本／读取模型列表，不附带档案。更改范围／账号／模型配置会取消并清空旧会话，不能交叉带入旧账号资料。
- 传输禁用重定向和 Cookie；外部服务要求 HTTPS，明文仅允许显式配置的回环／私网地址。模型不获得工具、文件或数据库操作权限。服务错误不得把响应正文、密钥或请求正文写入诊断日志。
- 输入资料、记录数、上下文字符、对话轮数和输出均有边界；覆盖说明区分全范围统计和选出的证据示例，截断必须说明。1M 等模型容量是可用上限，不表示默认上传全部记录。缺失字段、Partial／Unknown、源完成时间与采集时间沿用领域规范。
- AI 输出明确标为模型分析，系统提示要求引用证据、区分事实／统计／推断，不把推断改写成事实。无效引用不能当作有效本地证据；不完整、失败或取消的输出不作为完整历史重发。

## 范围

不更改 Schema 12 或公开 Portable／Archive 格式，不建立通用 Agent／工具执行、AI 自动采集、自动云上传或自建模型计费服务。会话与服务配置不混入可移植应用设置；后续持久化会话或备份支持需要独立契约。

## 验证

使用带恶意自由文本和身份标记的合成资料验证去标识化、范围隔离、统计一致性、证据定位、发送确认、流式完成／失败／取消和安全存储。真实模型服务验收只发送合成资料；未取得逐次授权不得用真实玩家档案替代。Windows UI、Android 构建与 Android 真机分别记录。
