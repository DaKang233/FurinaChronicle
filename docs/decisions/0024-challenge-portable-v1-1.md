# ADR 0024：挑战 Portable 1.1 与剧诗／危战观察

状态：Accepted
日期：2026-11-12

## 背景

Phase 10 要求深境螺旋、幻想真境剧诗、幽境危战三类挑战历史都能长期观察、查询与导出。ADR 0017 的 Portable v1.0 只写入深境螺旋楼层结果，剧诗／危战观察在导出时会丢失，且阶段级阵容、增益、敌人无处承载。

## 决策

1. 挑战 Portable 内部格式从 `1.0` 升为 `1.1`（`format_major = 1`，`format_minor = 1`，`dataset_kind = 2`）。
2. `mode` 接受 `1`（深境螺旋）、`2`（幻想真境剧诗）、`3`（幽境危战）；其他值仍按既有规则拒绝。
3. 观察新增可选字段：`stages`（阶段 ID、分数、完成时间、阵容、增益、敌人）、`difficulty`、`medal_count`。缺失字段按空值读取，旧 1.0 文件无需迁移即可读取；读取方忽略未知属性。
4. 阶段分数不做语义解释：剧诗沿用官方 `is_get_medal`，危战沿用秒数，展示层负责措辞；Portable 不推导“完成”节点。
5. Chronicle 的完成节点仍只由 ADR 0019 的深境螺旋 12-3 规则产生；剧诗／危战只作为挑战时间线中的详细观察，不进入主时间线完成节点。
6. 本次扩展不改变观察身份、判重、顺序、Plan／Apply 事务和资源上限语义。

## 后果

- Schema、示例与兼容测试同步更新；无需旧版 Migrator。
- 旧版本应用读取新文件时会忽略阶段详情（降级为楼层级数据），不得据此覆盖更高版本数据；写入方仍以 `format_minor` 标明能力。
- 公开发布前仍需 Windows↔Android 文件语义往返验证。
