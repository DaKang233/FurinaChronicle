# ADR 0008：离线优先的卡池事件元数据

状态：Accepted

## 决定

FurinaChronicle 将版本化的原神卡池事件数据集作为应用资源内置，使历史卡池识别在首次启动、无网络和公共元数据服务不可用时仍可工作。首个数据集由 Snap.Metadata 的简体中文 `GachaEvent.json` 提取，保留来源仓库、来源提交、许可证、语言、区服范围和数据集格式版本。

卡池事件身份不得依赖本地化名称或图片地址。事件区间按游戏、区服范围、卡池大类、开始时间、结束时间和期数建立稳定标识；同一期角色活动祈愿的 `301` 与 `400` 横幅属于同一个事件区间，但横幅身份及其原始抽卡类型分别保留。

Snap.Metadata 当前数据集按国服时间整理。已知国际服账号不得使用该数据集强行匹配；未知区服可以返回“区服未经验证”的匹配结果，但 UI 必须显式说明不确定性。

横幅图片不进入卡池数据集主体，只保存候选资源 URL。图片是可删除、可重建的缓存：读取相应卡池时按需下载，下载失败时不影响卡池文字和统计；用户可以预下载全部横幅图片，也可以清空全部横幅图片缓存。

## 更新边界

后续可以增加公开的 `IMetadataSource` 实现，从 Furina 服务端、官方 API 或经过验证的第三方来源取得更新数据集。下载的数据必须先完成格式版本、内容哈希、区服范围、时间区间和稳定标识校验，再原子替换本地的可更新快照。内置数据集始终作为离线基线和失败回退，不因网络更新被删除。

公共元数据更新不要求登录，不上传本地抽卡记录，也不读取米哈游凭据。来源之间出现冲突时保留来源信息并由卡池元数据专用合并策略处理，不使用显示名称覆盖身份。

## 历史投影

抽卡历史优先按已匹配的真实卡池事件区间聚合。无法匹配的数据必须保留，并退回按日期和卡池大类展示，标记为“未匹配卡池元数据”。卡池边界不重置抽卡保底统计。
