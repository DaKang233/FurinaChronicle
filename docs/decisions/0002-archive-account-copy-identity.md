# ADR 0002：档案内账号副本与共享角色身份

状态：Accepted

同一游戏角色可以在多个档案中存在。每个档案内副本具有独立 `GameAccount.Id`，所有业务记录分别归属，因此数据完全独立。另以跨设备尽量稳定的 `GameRoleIdentityId` 表示不同副本来自同一角色。同一档案内不允许两个相同自然身份的副本。

导入时重新生成本地 `GameAccount.Id`，但尽量保留共享身份 GUID。相同自然身份但 GUID 不同时映射到目标稳定 GUID；同 GUID 指向不同自然身份视为错误，不能静默修复。

当前数据库需要新增共享身份字段或表。共享身份不代表记录共享、自动覆盖或跨档案联动。
