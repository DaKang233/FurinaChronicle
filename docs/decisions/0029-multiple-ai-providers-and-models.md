# ADR 0029：多个 AI 供应商与模型配置

状态：Accepted（维护者 2026-11-22 要求参考胡桃增加多个供应商及模型选择）。

- 供应商具有独立本机 GUID、名称、协议、服务地址；其下保存多个模型配置，各模型独立保存标识、别名、额度与能力开关。名称不作身份，密钥不写入配置 JSON。
- 设置页管理供应商及模型；聊天页快速切换，保存会话的供应商/模型引用。新对话使用当前默认选择；历史每轮保留当时的供应商名称和模型名称，切换不改写原回答。
- 切换不自动发送；原发送草稿失效，下一次发送明确预览接收方及实际历史。原配置被删除时会话仍可查看，发送前要求重新选择，不静默改投其他服务。
- 密钥按供应商 GUID、规范地址和协议隔离；同地址的不同供应商不能互读。地址/协议改变不携带旧密钥。删除配置不删除会话；删除前说明影响，移除当前供应商密钥。旧地址的孤立安全存储槽可能仍存在，不宣称销毁全部历史密钥。
- 现有单供应商配置首次读取时迁移到内部版本化配置；旧密钥复制到新独立槽，成功保存后移除旧槽。失败保留原配置，不丢失原密钥。损坏及未来配置版本明确拒绝，不静默重置。
- 本次复用已有 OpenAI 兼容与 Ollama 协议；不因参考项目支持其他接口而隐含增加新的网络协议、工具或自动上传。模型列表由用户明确点击获取；允许手动添加模型。选择模型不自动宣称支持图片。
- 不改变业务 Schema、Portable/Archive 或 UID/永久删除保护；所有配置是设备设置，会话保存引用而非密钥。
