# ADR 0028：本地 AI 聊天、附件及设置页

状态：Accepted（维护者 2026-11-21 要求常见聊天能力、本地保存、文件与数据附件，并确认首轮文本/JSON/CSV/Markdown/图片；模型配置移入设置页）。

替代 ADR 0027 的“会话只在内存、离页清空”限制，保留只读领域、逐次发送确认和 UID 规则。

- 聊天独立保存在设备 AI 目录，版本化本地 JSON 文件原子替换；不修改业务 Schema 12，不作为领域 Portable/Archive，不进入默认遥测或云上传。保存标题、消息、状态、附件的本地副本及准备时证据，不能因整理网络上下文静默删除本地消息。
- 支持新建/搜索/置顶/重命名/删除/重开会话、停止/重试、编辑后重发、复制和 Markdown 导出。编辑/重新生成另建副本保留原对话；删除需确认，只删本机选中会话，不删除原始附件或领域数据。
- 生成前保存待处理消息，生成中有界检查点保存部分结果；重开将未结束生成标为中断。损坏或未来版本不得自动覆盖。保存失败不伪报成功，也不悄悄继续首次付费发送。
- 无需附加游戏数据即可普通聊天；附加游戏数据使用既有白名单。更换资料范围/重新准备数据会另开会话，保留原会话并隔离事实引用。离页保存并取消，不清空已保存历史。模型设置变化保留对话，但旧发送草稿失效，向新接收方发送仍须逐次确认。
- 文本文件经严格 UTF-8/UTF-16 解码及凭据/标识清理后提供模型；原文件名和路径不发送。支持 TXT/LOG/JSON/CSV/MD/XML/YAML，不执行文件、不按路径自动读取其他文件，不解压或处理 PDF/Word。文件正文视为不可信数据。
- 图片支持静态 PNG/JPEG/WebP，去除可识别的 EXIF/文本等容器元数据，不作 OCR；图片像素仍可能包含隐私。发送必须明确确认图片已去除 UID/凭据/个人标识，预览实际图片与摘要；未确认不得发送。单账号数据去 UID 的规则不被图片附件绕开。用户需自行裁剪/遮盖有标识的图片。
- 图片只发送给设置中由用户明确启用图片输入的模型；兼容接口使用 data URL 图片内容，Ollama 使用原生 base64 images。不自动上传到文件托管、获取远程附件或调用工具。不把密钥、原始错误正文、消息或附件写入诊断。
- 本地会话保留上限与网络上下文上限分开。发送前显示实际历史消息/附件和省略数量，超额旧消息只从本次请求省略，不删除本地记录；当前消息/附件超限时明确拒绝，不静默截断。存在档案 UID 的每次发送及追问仍明确弹窗确认；匿名模式按 UID 升序编号。
- 服务地址、协议、模型、密钥、额度和图片能力全部在设置页；聊天页显示当前模型并提供进入设置入口。API 密钥仍使用设备安全存储，不进入会话文件、报告或备份。

本轮不增加语音、联网搜索、工具执行、图像生成、自动代理、云聊天同步或 PDF/Word 解析。这些不是当前只读聊天实现的隐含授权。Markdown 仅作安全文本排版，不执行 HTML/脚本或自动加载远程图片。

维护者补充确认：永久删除前提示并要求先手动处理关联会话，不自动删除聊天。记录、账号及档案永久删除统一检查已保存/活动会话；相关会话未处理或文件损坏无法核实时拒绝删除。创建游戏资料副本与永久删除共享本机协调锁，防止检查之后再写入旧资料。普通用户文件/自由文本无法自动推断与账号的关系，需用户自行管理；不将其伪装成已可靠关联。
