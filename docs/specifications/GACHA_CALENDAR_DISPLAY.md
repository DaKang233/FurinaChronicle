# 抽卡日历展示

状态：Implemented（UI 与平台验收分别记录）

## 布局与统计

- 使用年度日期热力图。每列一周，每行对应周一至周日；日期向下、再向右推进，月份标注在首日所在列下方。
- 只统计当前选中账号，或当前档案范围中所选账号的本地抽卡记录；不把缺失记录推断为官方完整历史。
- 365／366 天全部显示，无抽卡日期为灰色，有抽卡日期采用五档蓝色。分级为 `ceil(当日抽数 × 5 / 当前年份单日最大抽数)`，不受其他年份影响。
- 两端共用 `GachaCalendarHeatmap` 的布局数据、统计与调色板，平台只负责控件和交互。图片、网络请求和数据库迁移均不是热力图的依赖。
- 默认最近有记录年份；无记录时显示当前年份。年份切换保持当前账号／档案范围。窄屏横向滚动，不缩小到无法辨认的密集文本。
- 主题变化同步更新零抽方格颜色，非零色阶不变。日期具有可访问性标签。

## 平台交互

- Windows：14 DIP 方格；保留上一年／下一年、年份与 UTC／UTC+08:00 选择。悬停显示当日抽数及五星／四星数量；点击进入同一时区的日期明细。
- Android 原业务页：18 DIP 方格；年份下拉、上一年／下一年；固定标明 UTC+08:00，点击高亮并在图下显示当日抽数及五星／四星数量。横向滚动查看全年。
- Android 离开页面时解除 ViewModel／主题事件订阅并清空日期控件；再次进入按当前数据重新构建，控件数量至多 366 个。不加载抽卡物品图片。
- Android 旧的逐日文字卡片被替换。既有 MAUI 预览的按月查询能力仍保留。

参考图中的“每天／每周／累计总量”不代表本轮新增三种统计模式；当前只呈现每日抽数分布。
