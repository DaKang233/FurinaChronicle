## 遗留与风险

1. **YSHelper 回退端点未确认**：本机参考中 YSHelper 只有抽卡历史／排行／复刻列表，没有物品元数据接口；当前回退到既有养成计算器元数据。若提供 YSHelper 元数据契约，可作为第二回退接入。
2. **图标 CDN 规则待确认**：接口自带图片地址直接保存；Snap.Metadata 只提供 `UI_*` 图标名，当前临时拼 Enka 镜像。确定官方 URL 构造规则后替换，并移除镜像依赖。
3. **Portable 公开发布边界**：挑战 `1.1` 属内部格式；公开发布前仍需 Windows↔Android 文件语义往返验证。本阶段只完成 Android 构建与既有格式的跨端能力验证。
4. **UI 重构并行线**：WinUI3 原生页面由独立 worktree 的会话推进；本阶段已把展示模型下沉到 `FurinaChronicle.Presentation/History`，后续复用同一服务层。
