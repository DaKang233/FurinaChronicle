## 范围与证据等级

目标是原 MAUI 抽卡业务能力和胡桃三个挑战页的个人记录内容。项目 Accepted Charter 将云备份／社区统计设为未来独立能力，不能为 UI 对齐自动上传记录。胡桃的全服统计、胡桃云上传、社区使用率／命座率和联网账号洞察不是本轮个人离线记录字段，不在本轮实现，亦不计作已经实现的功能。

证据分开记录：代码／自动化、实际 Windows 合成库 UIA、真实公共资源、真实账号采集、Android 编译和真机。某一层通过不代替其他层。

## 选择恢复的实施边界（本轮已落实）

复用现有选择存储接口，以独立的 gacha-selection.json（或等价设备本地位置）记住档案副本 GUID 与账号副本 GUID；不得按名称／UID 合并或转移记录，也不得复用其他业务页的当前选择。启动时校验归属和存在性；删除／失效／空库安全回退。每档案记忆其上次账号，与原 MAUI ArchiveSelectionService 行为对齐。

只恢复档案／账号；新会话默认仍为总览，不借机保存 URL、凭据、视图筛选或把设备选择加入 Portable 设置。写入按最新选择顺序落盘，正常关闭等待收尾；设置文件失败不得回滚事实或使业务页不可用。验证需覆盖两次进程启动、跨档案来回、其他页互不影响、失效选择和空档案／导入后新建目标。
