# WinUI 抽卡页选择恢复

状态：Implemented；设备本地设置，不是 Portable 或事实契约。

## 范围与隔离

抽卡页在 WindowsPaths.SettingsDirectory/gacha-selection.json 保存最后档案副本 GUID，以及每个档案最后选择的账号副本 GUID。复用 IArchiveSelectionStore 和 JsonFileArchiveSelectionStore，但使用独立实例及文件，不读写其他业务页面的 archive-selection.json。不按名称、UID 或共享身份选择另一档案的账号，不创建、移动或合并业务数据。

新进程恢复档案／账号；视图仍默认总览。筛选、档案多选范围、URL、凭据、图片和数据导入模式不新增持久化。设置不进入可移植白名单。

## 生命周期与失败

GachaReadOnlyState 可选接入 GachaSelectionPreferences；纯内存调用者保持原有行为。初次查询前读取上次档案，选择档案后优先使用当前实例记忆，否则读取该档案的保存账号。之后始终通过当前 Repository 查询的档案列表和该档案账号列表校验存在性及归属。

不存在的档案／账号或跨档案账号回退到首个可用项。空档案不借用其他档案的账号，空库保持空范围。只有当前未取消代际成功加载后才保存选择；失败查询不覆盖原设置。

设置写入顺序串行，连续选择最终以最后一次成功加载为准。相同选择不因分页／筛选重复写入；正常 CloseAsync 等待已有写入结束。存储使用同目录临时文件与替换，失败／取消清理临时文件。设置写入失败显示不包含原始异常路径的说明，保持业务页可用，不回滚已经提交的事实。损坏的 JSON 回退无选择，后续成功选择可以重建设置；这不是数据库修复。

## 验证与限制

- 自动化覆盖新对象读取真实设置文件、每档案记忆、其他页面文件独立、账号失效／跨档案／档案失效、空档案／空库、损坏文件、写入顺序、设置故障、失败恢复后的提示清除与业务读取失败。全量 Release 1267/1267，0 失败／0 跳过。
- 实际 Windows 隔离合成库：多个进程正常关闭重启、两个档案来回、默认总览、管理页往返、损坏文件、错误归属／不存在账号和空档案均通过 UIA 定位及键盘操作验证；并核对最终落盘 GUID。
- 测试前后档案、账号、共享身份和全部 Gacha 行逐行相同，quick_check 和外键检查通过。未访问生产数据库或凭据。
- 证据：E:/Workspace/FurinaWorkspace/.validation/gacha-selection-20261119。
- 不提供旧 MAUI 操作系统 Preferences 的自动迁移；不增加 Android 页面或跨设备设置同步。


## 本地读取期间的选择交互

档案、账号与视图选择框在普通本地读取中保持可用，有效范围变化可取消并替代旧查询。选项 ID 和显示内容未改变时不重建原生选项对象，避免无意义的弹出层／焦点重建；真正重命名、增删仍更新。已退出或过期查询由原有状态代际保护，不回写新选择。

这不解除刷新、导入、导出及数据操作的既有锁。空档案无账号时账号选择框禁用；未初始化或无档案时不允许选不存在的范围。

实际 Windows 验证含第三个账号、空档案往返和五个视图连续键盘切换，详见 E:/Workspace/FurinaWorkspace/.validation/winui-resource-soak-20261119。
