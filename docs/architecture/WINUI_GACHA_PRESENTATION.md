# Windows 抽卡展示实现与验证

状态：2026-11-20 实施，适用于独立 WinUI 宿主。本轮由维护者授权使用已登录真实账号验证图标和刷新；私有截图、数据库副本及凭据不进入仓库。Schema 12、Portable、Archive 和写入／Undo 语义不变。

## 图标的实际调用路径

Windows 的 SToken、手动 URL、Windows 缓存及未选目标刷新统一使用注册的 `RefreshGachaRecords`。`STokenRefreshComposition` 注入正式物品元数据提供者；公共元数据暂不可用时保存原始官方事实，不因可选图片依赖丢失记录。原子提交、Tombstone 抑制及全量校正规则不变。

此前 Windows 刷新与统计组合使用空元数据提供者；官方响应没有 item_id 时，已保存记录及图片引用均缺 ID。现在统计使用 `CachedGachaItemMetadataProvider`，图片展示经 `GachaArtworkResolver` 解析已有 ID，或对缺 ID 的记录作可选名称查找。名称仅用于图片／读取补全，不成为事实身份，也不静默改写已有记录。已有 ID 不被名称查找替换；其他游戏／冲突的元数据不能覆盖已知 ID。

`GachaArtworkConverter` 为数据模板返回可观察图片状态，下载最多四项并发，切换范围取消旧代际。相同引用不重复清空 Source；页面内状态及原生位图均采用最多 512 项的弱引用索引。文件版本变化后按新修改时间／长度创建位图，继续保留解码尺寸和 IgnoreImageCache。图标文件仍按游戏＋物品 ID 复用，30 天更新失败使用旧图。

## 总览

卡片宽度 300 DIP，标题即统计折叠开关，使用当前视口实际高度，五星区域独立滚动。图标为 40 DIP，保持时间倒序、先行后列。列表以头像、背景矩形抽数条、物品名和右对齐抽数显示；普通角色／武器标尺为 90／80，角色活动真实抽数标尺为 180，未知间隔明确显示未知。它只是同一统计结果的呈现，不由条长度反推事实。

保留角色活动真实抽数开关、图标／列表切换、账号手动分批加载；档案聚合继续按物品数量排序并分批加载。数据模板通过 ICommand 执行按钮操作，视口高度通过绑定更新。

## 历史

左栏显示全部符合范围的独立限定卡池、版本、日期和 UP 物品获得数量；原生 ListView 虚拟化，无历史分页／版本过滤。右栏显示选中卡池横幅和物品，图标／文本模式保留。明细与物品分页、日历年份切换不受影响。

没有横幅操作按钮。进入／重新载入历史时自动批量缓存，单项失败不阻塞其他项；已有图片可离线使用，缺图期间文字／统计可用。批次完成后更新当前详情，下一次进入／重新载入重试失败项。图片模板仅读取横幅缓存，不在每张 Image 载入时触发冷横幅请求。

## 物品

移除 Windows 的列表与时间模式。点击网格物品，在固定右栏查看名称、类型、数量及当前范围内的获取时间；时间先展示 50 条，再由用户手动追加。账号／档案均按当前选择范围读取，三星也可由明确点击查看；不声称包括活动赠送、商城等非抽卡来源。

`GachaItemCard` 保留旧默认隐藏规则以兼容 MAUI，新增显式 `OpenDetails` 供 WinUI 使用。本轮不重构 Android 的页面布局，不把共享类型构建成功当作真机触摸验收。

## 原生异常调查

受控公共横幅失败／重新加载测试曾触发 0xc000027b。该合成实例的转储显示 XAML 模板构建订阅 Loaded 时进入 WinRT EventSourceCache.Create，经 STA 消息泵产生 XAML 受保护重入（stowed 8000ffff）。这是本机调用栈证据，不将它泛化为所有崩溃或上游缺陷。

实现移除 Gacha 数据模板中的逐项原生事件连接，改用图片状态、命令和高度绑定。完整历史列表保留，未通过分页或截断目录规避问题。同一故障场景重跑后，实际缺失横幅下载并可见；20 次列表首尾滚动／选择、四轮总览→物品→历史→重新载入正常，窗口正常关闭。

## 验证边界

- 真实账号：缺 ID 的既有官方记录可只读解析并显示图标；SToken 增量请求成功，本次无新增记录，不能据此宣称现场验证了“新增一抽”的保存全过程。新增缺 ID 的保存路径由合成官方响应及正式服务测试覆盖。
- Windows 实际交互：紧凑总览列表、完整卡池首尾、移除旧按钮、物品点击右栏均通过；鼠标十次移入／移出共 40 帧采样，头像内部像素不变。有限采样不构成所有时序的无闪烁保证。
- 公共横幅故障：独立合成生产布局目录中，仅隔离一张已备份图片并拒绝对应公网连接；其余缓存／文字可用，重新载入后真实公共图片下载并实际显示。没有拦截登录请求或解密 TLS。
