# Windows 周期挑战展示

状态：2026-11-20 实施。维护者提供胡桃／FufuLauncher 参考图及游戏素材；本轮改进读取与 Windows WinUI 展示，并修复剧诗新采集的幕次映射；不重写既有观察、身份、来源、时间或完整度，不改变 Schema 12、Portable 或 Archive 格式。

## 敌人信息从哪里来

深渊期次配置来自 Snap.Metadata，默认下载基址由 `SnapMetadataOptions.BaseAddress` 指向 SnapHutaoRemasteringProject/Snap.Metadata 的 Genshin/CHS。`SnapMetadataClient.Abyss` 以期次 ID 关联 TowerSchedule.FloorIds → TowerFloor.LevelGroupId → TowerLevel.GroupId，再以 Monster.DescribeId 取得名称及图标；First／Second 数据对应上下半。波次、数量、词缀、机关和地脉异常都是公共配置，不表示玩家实际击破。

配置缓存位于所选数据目录的 `Data/metadata/SnapMetadata/versions/<版本>/`，按该客户端实例选定版本读取。它不是冻结在每次观察内的敌人配置；缺失的精确期次／楼层明确显示缺失，不能拿别期兜底。现有官方响应中已经保存的敌人仍作为响应信息单独显示。玩家阵容、星数和已知秒级完成时间来自保存的官方观察，绝不由配置推断。

敌人图标使用 `SnapMetadataOptions.MonsterIconBaseAddress`，默认 static.snaphutaorp.org 的 static/raw/MonsterIcon 目录。资源通过既有受信 HTTPS／重定向验证与文件缓存；不发送玩家凭据。详细关联及缺失规则见 [挑战展示元数据](CHALLENGE_DISPLAY_METADATA.md)。

## 导航与深渊

- 左侧两栏分别为全部已保存期次及选中期次的采集快照；期次按已保存周期起止倒序、再按最近观察排序，避免后请求的上期成为默认期次；手动选择在重新载入后保留。快照仍有每页 20 条的有界查询与前后翻页。快照翻页不等于楼层切换。
- 首次选择期次默认最新观察，用户可查看旧快照。列表使用真实 ObservedAt；只有 FetchedAt／ImportedAt 时明确标为抓取／导入，不能把战斗完成时间或当前时间当作采集时刻。
- 右侧只渲染当前快照的当前楼层，按楼层选项卡切换，默认最高已保存层。每间的上下半并排，左上半／右下半，各有阵容、完成时间、配置波次和说明。已保存但缺少半场详情的间仍可见，不由配置补造队伍。
- 渊月祝福保留在详情顶部；六类统计从纵向大图卡移入“统计数据”弹窗，以名称、值和小侧头像显示。侧头像不套品质底图。

`ChallengeDetailSection.Kind / Number / Chambers` 仅是读模型。旧扁平 Lines／Battles 保留给 MAUI 与已有调用方，不通过解析本地化标题来重建上下半关系。

## 幽境危战

单人／联机使用独立选择、总览与关卡。总览以并列卡片展示源难度、最佳用时，以及当前关卡记录中已提供的最高总伤害（界面聚合）。无成绩、缺值与零值分开，不把伤害当 DPS，也不以难度编号猜测缺失徽章。

每关显示强敌名称／已知等级；“强敌机制”逐段展示快照中的全部非空描述，“强敌特性”显示官方标签。仅在读模型中过滤空白占位，段落顺序、重复段落、换行和富文本均保留；旧快照缺少说明时明确提示，不借用别期或最新 API 文本回填。每关包含敌方信息、富文本机制、队伍和最佳角色。最强一击／最高总伤害使用返回的侧头像和独立指标，不套星级底图。队伍图像保留品质、等级、名字和已有来源标签；发生时间未知的规则不变。

## 幻想真境剧诗

顶部展示本期准入元素及开幕／特邀角色（公共期次配置，不能表示玩家持有），然后展示已有官方演出统计、战斗指标、最快演出和待命角色。缺失配置明确提示；官方关闭战斗统计时遵循原隐藏规则。

每幕包含已知完成时间、奖章状态、敌人／队伍、辉彩祝福总览及图标、神秘收获图标。祝福图标悬停提供完整富文本说明，也支持点击／键盘固定查看。内部图片不再提供竞争的简短 tooltip。没有字段时保持未知，不从相邻幕推断。

演出徽记 UI_RoleCombat_Medal_S_* 对应源 Heraldry，不对应 Difficulty；塔罗与普通幕的奖章素材分开，并依据实际已知奖章状态选择。用户提供的 Abyss／Navigation／RoleCombat 图片由 Windows Content 链接到 Assets/Challenge，原文件不移动／改名。

## 富文本与图片生命周期

`HoYoRichText` 是纯展示解析器，保留 color（RGB／RGBA／短 RGB）、b、i、u、size 和 br；字体大小及嵌套有上限。原神内部术语 `{LINK#N211101}电涌{/LINK}` 显示为带下划线的“电涌”，Run 保留 N211101 引用编号；支持与颜色、粗体、斜体嵌套，关闭后不泄漏样式／引用到后文。未知语法保留为可读文字，不执行 HTML 或将术语编号转换为外部网址。当前不声称提供游戏内术语百科解析。

纯文本展示使用同一解析器取得文字，例如上述术语显示为“电涌”，不泄漏控制标记。公共元数据读取不提前删除颜色；富文本 Run 与旧纯文本投影分别呈现。原始观察、元数据文件和可移植载荷保持原样。

图片改为绑定式异步状态，不逐张订阅 Loaded／Unloaded／DataContextChanged。只为当前展示的快照／楼层建立控件，切换时取消旧加载；最多四项并发、最多 512 项弱引用索引，复用已有公共图片文件和有界解码位图。缺图保留名称／提示，不阻止事实读取；普通本地读取不在 SelectionChanged 内禁用或销毁原生选择器，真正采集期间才锁定范围。

## 本期与上期的在线采集（2026-11-20 补充）

Windows 和 MAUI 正式采集均检查所选模式的本期与上期。深渊使用 ExecuteRecentAsync，串行请求 schedule_type=1／2；剧诗与危战解析一次响应中的两期有效记录，不再 FirstOrDefault 丢弃后一项。显式单期 ExecuteAsync 仅留给既有隔离诊断，正式页面不再调用。没有玩家数据的期次正常跳过，不合成空成绩或用另一期间数据代替。
